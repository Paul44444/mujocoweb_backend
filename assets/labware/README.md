# Labware assets

Prepared from the user's existing local `test_tube_mutations` USD export.

- `test_tube.usda`: centered, metre-scale single tube wrapper.
- `test_tube_rack.usda`: centered, Z-up rack-only wrapper.
- `source/tube_visual_clean.usda`: flattened visual-only tube with imported physics metadata removed.
- `source/`: original USD dependencies and textures retained for portability.

Physics uses simplified collision geometry in `isaac_labware_task.py`; these wrappers provide detailed rendering. Verify the original asset license before redistributing the source files outside this project.
