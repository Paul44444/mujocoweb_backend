# CO2 incubator

Source: https://polyfork.dev/asset/co2-incubator-198c16 (Polyfork / Lucas Martinic).
Downloaded by the project owner as `co2-incubator-198c16.glb`.
The model page describes free use in games/apps/client projects with no required
attribution, but forbids reselling raw assets or building a commercial asset
generator from them. Follow the licensing link on the source page for current terms.

`build_incubator_asset.py` generates an integrated simulation derivative:
Y-up to Z-up, scale 0.4 (36 cm wide), original vertex colours and door pivot,
empty chamber (decorative cultures removed), added compound cavity colliders,
fixed base and actuated revolute door joint. Door collision is approximate,
not a precision replica of the mesh. No generative model training uses this asset.
