# Pretrained tube pickup (separate experiment)

This is **NVIDIA GraspGenX grasp inference + Isaac Lula IK + staged arm motion**.
It is not GEN-1.5, an end-to-end learned manipulation policy, or a PPO
checkpoint. Grasp predictions were generated by the released pretrained
generator/discriminator, not hand-written. Arm approach/closure/lift is explicit.

The new environment `Isaac-Franka-GraspGenX-Tube-Pick-Play-v0` places the
existing tube horizontally on two physical supports. The original upright
test-tube, placement, cube, vision and MuJoCo environments are unchanged.
There is no object attachment or object teleport during execution. Reset is
the normal environment reset.

## Website

Under Isaac Lab choose **GraspGenX · Pretrained Tube Pick** in the task selector.
The pretrained controller is selected automatically. Start/Pause control it;
Reset repeats the pickup. It is playback-only; use the original Stage 1 task
for BC/PPO. Existing checkpoints are not overwritten.

The dedicated start-variation controls sample independent uniform XY offsets
up to ±5 cm and a world-Z yaw up to ±30 degrees on manual Reset. Tube and
kinematic supports receive the same rigid transform, preserving their layout.
Zero ranges restore the original configuration without accumulating offsets.
Changing a slider does not teleport anything during a running pickup. Start
with ±1 cm; failures at larger ranges are possible. This tests grasp-coordinate
transfer and the IK/execution pipeline, not camera perception.

## Scope and limitations

- Candidates are precomputed for the current 7.5 mm radius / 92 mm cylinder.
  They transform with the object's actual pose; new object geometry requires
  new inference. This version uses simulator pose, not camera pose estimation.
- The official gripper URDF's `world -> panda_hand` rotation is +90 degrees.
  The controller applies that conversion, the parallel-gripper symmetry,
  table-clear mesh bounds and a Lula reachability check.
- A tested 8 mm finger-pad seating allowance adapts the candidate to the
  Isaac collision pads. This is configuration-specific, not universal.
- The smoke test requires a lift of at least 15 cm held for 10 simulated
  seconds before publishing `assets/graspgenx_tube.json`. That is a smoke test,
  not a measured general-purpose success rate or a packaging task.
- The fixed supports leave room for the fingertips. Upright lateral pickup
  was not reliable in our earlier tests and is not advertised as solved.

## Local files and reproduction

Official repository: `/home/paul/.local/share/mujocoweb/pretrained/graspgenx`

Isolated inference Python: `/home/paul/.local/share/mujocoweb/pretrained/graspgenx-venv/bin/python`

Weights: `graspgenx/ext/graspgenx_checkpoints/release/{gen,dis}`.
Franka assets: `graspgenx/ext/gripper_descriptions/gripper_descriptions/assets/x_grippers/franka_panda`.
These external downloads are not committed to our repositories and do not
change the Isaac Python dependencies.

Generate candidates with `graspgenx_prepare.py` using the isolated interpreter
and `--repository` / `--output-directory`. Set `GRASPGENX_CHECKPOINT_DIR` and
`GRASPGENX_GRIPPER_CFG_DIR` to the repository's corresponding `ext` directories.
Use `--reuse-predictions` to rebuild metadata from existing inference YAML.

Validate/publish using the Isaac interpreter, from this backend directory:

```bash
/home/paul/miniconda3/envs/env_isaaclab1/bin/python test_graspgen_pickup.py --headless --device cuda:0 --grasps /home/paul/.local/share/mujocoweb/pretrained/tube/tube_grasps.json --validation-output assets/graspgenx_tube.json
```
